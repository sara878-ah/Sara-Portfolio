# Hospital Visit Log — Live Demo

A Flask and SQLite web application for tracking hospital service visits, documenting operational issues and resolutions, and managing team workflows.

## Try the live demo

**[Open the live demo](https://hospitaldemo.pythonanywhere.com/login)**

| Field | Demo access |
|---|---|
| Username | `demo` |
| Password | *Demo password will be added by the project owner* |

> **Demo environment only.** All preloaded records are fictional. Please don't enter personal, patient, or confidential business information. Visitors share the same demo account, so trial entries may be changed or deleted by other visitors.

## Main features

- User authentication with hashed passwords
- Employee and supervisor roles with role-based access controls
- Record visits, issues, causes, outcomes, and follow-up notes
- Search and filter visit records
- Export visit records to Excel
- Supervisor-only user management and team notes

**Demo limitations:** This shared account has the employee role and cannot access supervisor-only user management pages. Visitors can try permitted visit workflows using fictional records; shared demo content is not persistent personal storage.

## Technology

Python · Flask · SQLite · HTML · CSS · Werkzeug · openpyxl
