# Blind Talk 🎮

A responsive Arabic conversation game for two people, built with **HTML, CSS and vanilla JavaScript**.

## Play

- **[Play Blind Talk](https://sara878-ah.github.io/Sara-Portfolio/Blind-Talk/)** (GitHub Pages — requires Pages enabled for this portfolio)
- [Source files](./)

## How it works

1. Enter two names and choose a conversation category.
2. Draw a random topic and discuss it together.
3. If needed, reveal a helpful discussion prompt.
4. Each player privately rates the conversation from 0–10.
5. Continue with more rounds, or end the session to reveal **all ratings organized by topic**.

Ratings are only shown when the game ends, and **no average score** is calculated.

## Files

- `index.html` — interface
- `styles.css` — responsive design
- `topics.js` — topic library
- `app.js` — rounds, private ratings, final results and sharing

The game uses local browser storage. It does not require a login or a backend. This is a browser game, not an App Store download.
